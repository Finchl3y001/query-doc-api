NOW: Full WSL Setup Guide (Step-by-Step)

I’ll give you a clean, reliable setup from scratch.

🚀 STEP 1 — Install WSL2 + Ubuntu

Open PowerShell as Administrator and run:

wsl --install -d Ubuntu


Then reboot.

After reboot, open Ubuntu from the Start Menu and let it finish installing.

🚀 STEP 2 — Update & Upgrade Ubuntu

Inside Ubuntu:

sudo apt update && sudo apt upgrade -y

🚀 STEP 3 — Install Essential Packages
sudo apt install -y git curl wget python3 python3-pip build-essential jq unzip

🚀 STEP 4 — Install Go (needed for many tools)
sudo apt install -y golang


Verify:

go version

🚀 STEP 5 — Install API/Recon Tools
subfinder
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest

httpx
go install -v github.com/projectdiscovery/httpx/cmd/httpx@latest

nuclei
go install -v github.com/projectdiscovery/nuclei/v2/cmd/nuclei@latest

ffuf
go install github.com/ffuf/ffuf@latest

gau
go install github.com/lc/gau/v2/cmd/gau@latest

waybackurls
go install github.com/tomnomnom/waybackurls@latest

amass
sudo snap install amass

linkfinder
pip3 install linkfinder

🚀 STEP 6 — Add Go tools to PATH

Add this to your ~/.bashrc:

export PATH=$PATH:/home/$USER/go/bin


Reload:

source ~/.bashrc

🚀 STEP 7 — Install Docker (Optional but recommended)

This gives you the ability to run containers and labs for testing.

In PowerShell:

wsl --install -d Ubuntu --enable-wsl-docker


Or manually install Docker Desktop → Settings → Enable WSL2 backend.

🚀 STEP 8 — Install Burp Suite (on Windows)

Download Burp Suite Community or Pro (Windows)

Install normally

Set browser proxy to:

127.0.0.1:8080


To allow WSL tools to send requests through Burp, add Burp listener:

Burp → Proxy → Options → Add → Bind to 127.0.0.1

🚀 STEP 9 — Connect WSL to Burp Suite

Inside WSL, set proxy variables when needed:

export http_proxy=http://127.0.0.1:8080
export https_proxy=http://127.0.0.1:8080


Now WSL tools → Burp → internet.

Example:

curl -x http://127.0.0.1:8080 https://example.com


You will see the request in Burp.

🚀 STEP 10 — Install Postman (on Windows)

Download Postman (Windows).
Everything just works.

If you want Postman → Burp → API:

Set Postman's proxy to 127.0.0.1:8080

Or use Burp's built-in “Upstream Proxy” settings
